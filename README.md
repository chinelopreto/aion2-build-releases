# Worthy Profissional - AION 2 Build

Otimizador de build, sobreposição, guia no jogo e scanner de tela para AION 2.

## Download

Baixe a versão mais nova em **[Releases](https://github.com/chinelopreto/aion2-build-releases/releases/latest)**:

- `WorthyProfissional-AION2Build-Setup-<versão>.exe`: instalador (recomendado).
- `Worthy Profissional - AION 2 Build v<versão>.exe`: portátil, não precisa instalar.

## Atualização

A partir da 1.7.4 o programa procura versão nova aqui sempre que abre e pergunta se quer atualizar.
Também dá para procurar na hora em **Configurações › Atualizações › Procurar atualização**.
Seus personagens e configurações ficam em `%APPDATA%\AION 2 Build` e são mantidos ao atualizar.
